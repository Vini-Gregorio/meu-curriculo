# Capturas dos projetos

Os cartões utilizam estas imagens existentes:

- `mq-fire.webp` — interface do MQ-FIRE.
- `mirante-canaa.webp` — site do restaurante.
- `high-business-class.webp` — interface do site de transporte executivo.
- `mq-fire-academy.webp` — interface da plataforma educacional.

Para atualizar uma captura, substitua o arquivo correspondente. Os arquivos atuais contêm imagens PNG apesar da extensão `.webp`; o navegador consegue exibi-los. Caso altere a extensão para corresponder ao formato, atualize também o caminho em `index.html`.

Prefira imagens com largura de 1200 a 1900 pixels e proporção próxima a 16:9. A prévia preenche o cartão com `object-fit: cover` e mantém o topo visível. Se uma imagem não carregar, o cartão exibe o nome do projeto e sua área de atuação.

ContabilWeb e Flo usam composições em HTML e CSS que mostram a estrutura do código. Elas são identificadas como estrutura do projeto ou conteúdo do repositório e não representam capturas das aplicações.
